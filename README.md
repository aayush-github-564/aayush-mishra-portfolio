# Aayush Mishra — Portfolio

A responsive, animation-rich portfolio built with React, TypeScript, and Vite. The content is based on Aayush's resume and links to the GitHub repositories listed there. It includes the supplied logo variants, a resume download, a cursor-reactive character, a fixed contact rail, and direct contact links.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create the deployable site in `dist/`.

The email buttons open a Gmail compose window addressed to Aayush. The resume is served from `public/Aayush-Mishra-Resume.pdf`. The site uses Space Grotesk and DM Mono from Google Fonts, with local system-font fallbacks. The hero character and tech-stack animation are built from inline SVG and CSS.
